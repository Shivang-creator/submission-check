# The rule pack — every rule came from a real loss

Each check below is traceable to a hackathon this author entered. No hypotheticals.

| # | Rule | Where it came from |
|---|---|---|
| 1 | **No test count stated** | ProofPrint, Backblaze (did not place). Winners led with "358 executable assertions" and "485 tests". ProofPrint had one 122-line script and never mentioned it. Two of four criteria were about production readiness. |
| 2 | **Headline number buried** | ProofPrint's best number — a sealed PNG cut 34× to a metadata-stripped JPEG, still resolved at 0/64 bits — was item 3 of a sub-list. The Grand Prize winner's equivalent was the first line: "9.3s vs 65.7s on job j_47cdc2, live, check it yourself." |
| 3 | **Audience deferred to "What's next"** | ProofPrint's only named buyer appeared in the roadmap. The criterion asked "is there a clear audience?" and the answer was postponed. |
| 4 | **SDK bugs written as complaints** | ProofPrint found three excellent Genblaze bugs and filed them under "Challenges we ran into." FirstFrame filed 3 PRs and an issue with reproductions and failing tests, and led with it. Same discovery, opposite disposition. |
| 5 | **Opens with a regulation, not a person** | ProofPrint opened with "EU AI Act Article 50 became applicable." FirstFrame opened with someone waiting four minutes to watch four seconds and say no. |
| 6 | **No visible failure** | Every Backblaze winner kept one: a retained failed attempt, a `TEST FAULT` badge, an `UNKNOWN` field. Perfect surfaces read as untested. |
| 7 | **Guarantee asserted, never attacked** | ProofPrint *probed* Object Lock at startup. FirstFrame *issued a real delete and asserted the refusal.* |
| 8 | **Required links missing** | Repo, live URL, demo video. Mechanical, and people still lose on it. |
| 9 | **Rules not read** | Over half the IncludAI field broke a hard rule (a real neurodivergent user in design or testing). |
| 10 | **"Works with no API key" not said up front** | Three strong Backblaze entries made it a headline. It removes the biggest reason a judge never tries your project. |
